### Проверка текущего NTP-сервера
Для просмотра текущей конфигурации и статуса синхронизации используйте утилиту w32tm: \
Показать текущую конфигурацию: w32tm /query /configuration \
Показать текущий статус (источник времени, stratum, индикатор leap, точность, время последней синхронизации): w32tm /query /status \
Вывести текущее системное время: time /T \
